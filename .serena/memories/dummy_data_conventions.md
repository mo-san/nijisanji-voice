# ダミーデータ命名規則

このプロジェクトでは、テストやサンプルコードで実在する人物名や団体名を使用しない方針を採用しています。

## キャラクター名（アーティスト名）

ファンタジー系の架空の名前を使用します：

- **エリアナ** (Eliana) - 4文字の全角文字、表示幅8
- **セレスティア** (Celestia) - 6文字の全角文字、表示幅12
- **リュウ** (Ryu) - 3文字の全角文字、表示幅6
- **アルテミス** (Artemis) - 5文字の全角文字、表示幅10

## アルバム名／ボイス名

ファンタジー・神話・自然をテーマにした名前を使用します：

- **ファンタジーボイス** (Fantasy Voice)
- **月光ボイス** (Moonlight Voice)
- **ドラゴンボイス** (Dragon Voice)
- **星空ボイス** (Starry Sky Voice)

## トラック名／曲名

詩的で抽象的な名前を使用します：

- **夜想曲** (Nocturne)
- **星の唄** (Song of Stars)
- **銀河の調べ** (Melody of Galaxy)
- **流星の詩** (Poem of Shooting Stars)

## 使用例

### 標準的なファイル名パターン
```
エリアナ_ファンタジーボイス.mp3
セレスティア_月光ボイス.mp3
リュウ_ドラゴンボイス.mp3
```

### トラック番号付きパターン
```
01_アルテミス_星空ボイス.mp3
セレスティア_月光ボイス_1_銀河の調べ.mp3
```

### EXパターン
```
EX_エリアナ_ファンタジーボイス.mp3
EX Another_セレスティア_月光ボイス.mp3
```

## 注意事項

- 実在する人物名や団体名は使用しない
- 「テストアーティスト」「テストボイス」のような無機的な名前は避ける
- 既存のテストで使用されているファンタジー系の名前に統一する
- 全角文字の表示幅を意識したテストデータを選ぶ（例: 4文字=8幅、6文字=12幅）
